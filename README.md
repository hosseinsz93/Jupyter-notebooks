Jupyter Notebooks Repository

Welcome to my Jupyter Notebooks repository! This repository contains various Jupyter notebooks covering different topics, including data analysis, CFD post-processings, numerical simulations, and more.

The repository is organized as follows:

│-- ACF/

│-- UNH-RVAT-validation/

🚀 Getting Started

1️⃣ Clone the Repository

To clone this repository to your local machine, use:

git clone https://github.com/hosseinsz93/Jupyter-notebooks.git

2️⃣ Open Jupyter Notebook

Navigate to the repository folder and launch Jupyter Notebook:

cd Jupyter-notebooks
jupyter notebook

📌 Notebooks Overview

ACF/: Turbulence statistical analysis and autocorrelation function.

Heatmap/: Generates heatmaps based on fish experimental results.

TurbineInpAnholt/: Generates Turbine input file for wind/tidal farms.

UNH-RVAT-validation/: Validation studies and analysis based on the UNH-RVAT dataset.

fish-velocity/" Script for measuring fish velocity from experimental results.

savepoints-generator/: Scripts for generating savepoints.

turbulence-regions/: Notebooks focusing on turbulence statistics at different turbulence regions.
